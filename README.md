# java-calculator-precourse

## 구현할 기능 목록

### 입력 처리
- [X] 사용자로부터 문자열을 입력받는다.
- [X] 입력값이 비어 있는 경우 0을 반환한다.

### 문자열 파싱
- [X] 기본 구분자(쉼표 `,` 또는 콜론 `:`)를 기준으로 문자열을 분리한다.
- [X] 커스텀 구분자(`//<구분자>\n`)가 존재할 경우 이를 추출한다.
- [ ] 추출된 커스텀 구분자를 사용하여 문자열을 분리한다.

### 검증 (Validation)
- [ ] 입력값 중 숫자가 아닌 문자가 포함된 경우 `IllegalArgumentException`을 발생시킨다.
- [ ] 예외 발생 시 프로그램은 종료되어야 한다.

### 계산
- [ ] 분리된 숫자 문자열을 정수로 변환한다.
- [ ] 모든 숫자의 합을 계산한다.

### 출력
- [ ] 계산 결과를 `결과 : <합>` 형식으로 출력한다.
